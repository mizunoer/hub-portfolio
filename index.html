Dallin: Building AI into real-world work

Dallin designs, builds and runs AI functionality that does real work. Everything on this page comes from one working system, designed and operated end to end: several GPU machines behind a single AI hub that labels every request, routes it to the model that measured best for it, keeps private data on its own hardware, remembers what matters, drafts routine work for a human to approve, and tests itself every day. What this demonstrates

Practical AI engineering, from model choice to privacy to operations.

AI wired into everyday work

Mail triage and reply drafts, documents turned into searchable text, long-term memory and new-machine setup all run on AI the owner built, every day, not in a demo.

The right model for each request

Every request is labelled by a small classifier and routed to the model that measured best for that kind of work, across several GPU machines and free external providers.

Privacy enforced in code

Private content never leaves the owner's own hardware. The rule is enforced by the router, and every public output (this page included) is scrubbed before it is written.

Evaluation over hype

Models are rated on an in-house test suite with independent judges; a challenger replaces a model automatically only when it is 30% better at the same cost and speed, with a rollback.

Runs and checks itself

A daily end-to-end smoke test, a GPU residency watch that repairs itself, hard ceilings on every automated call, and a numbered decision record for every design choice.

AI at work in real scenarios

Each job the system does in daily use, the manual work it replaces, how much of it runs on its own, and what a person still decides.

Remember what matters

Replaces: Repeating context in every chat

Turn documents into markdown

Triage mail

Replaces: Reading every message to find what needs a reply

Draft mail replies

Replaces: Writing routine replies from scratch

human-led Built with hub-core comms · local model, Spark drafts

Human part: Approve each draft; the hub never sends mail

Rate external models

Replaces: Trusting leaderboards

autonomous Built with learning router: rate + judge · 68-case suite, two free judges

Human part: None; nothing real is sent, only synthetic test prompts

Set up a new machine

Replaces: An evening of installs per machine

assisted Built with installer v4.1 · Ubuntu autoinstall + fleet-finish

Human part: Plug in the stick and pick it at boot (F11 on the MSIs)
